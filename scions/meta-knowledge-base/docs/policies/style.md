# Style policy

Keep documentation:
- plain language
- concrete and specific
- concise (policies: 20-40 lines, playbooks: 50-100 lines)
- structured with headings and short sections
- bullet points over paragraphs

Avoid:
- vague claims without sources
- walls of text without navigation
- verbose examples
- unnecessary elaboration

Context size matters. Documentation is consumed by LLMs.
